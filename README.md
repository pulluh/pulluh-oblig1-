# pulluh-oblig1-
This project is a simple Python application created to verify that the Python environment, Git workflow, and repository structure are correctly set up. It serves as the first obligatory assignment before moving on to more advanced programming tasks.


## Installation Instructions
1. Clone the repository in bash:
   git clone https://github.com/pulluh/pulluh-oblig1-/branches.git
   cd pulluh-oblig1
   

2. Create a virtual environment in bash:
python3 -m venv venv

3. Activate the virtual environment in bash:
macOS / Linux: source venv/bin/activate
Windows: venv\Scripts\activate

4. Run the application:
python hello_health.py

---------------
## Requirements

Python 3.10 or higher

No external dependencies for Obligation 1
